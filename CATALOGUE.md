# Tiny Town building catalogue

100 buildings inspired by an OpenTTD-style isometric city. Each one is built by
one agent in one PR that touches only `buildings/<slug>/` (see [CONTRIBUTING.md](CONTRIBUTING.md)).

- **slug** is the folder name: `buildings/<slug>/`. Use it exactly.
- **footprint** is `w x d` in tiles (1 tile = 10 m); width runs along X, depth along Z, the front faces +Z.
- **category** must be copied into `meta.json` as-is.
- **Do not edit this file in a building PR.** The gallery shows which buildings exist automatically,
  so the status column only marks the two examples that ship with the scaffold.
